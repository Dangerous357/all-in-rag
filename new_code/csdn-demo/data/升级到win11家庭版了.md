# 升级到win11家庭版了

### 如果你和我一样，对计算机懂一点但又不完全懂，听我的，不要升级！会变得不幸！

一、关于Win11的常见问题（持续编辑中）
---------------------

### 1.升级相当于重装系统吗？

答：应该不是，毕竟我升级完之后，电脑的所有东西都还在（目前来看是这样的）。编译器环境变量也都是以前设置好的，可以正常使用~

### 2.C盘里的windows.old文件夹

升级完系统之后，C盘里会多出一个windows.old文件夹，很明显是用来装以前的文件的，用来回滚（如果你和我一样后悔的话，可以退回到win10系统）  
 我虽然后悔，但我决定好马不吃回头草，把后路断了……  
 **删除windows.old文件夹**  
 [系统更新后旧系统文件能不能删除](https://zhidao.baidu.com/question/1770359686310083220.html)  
 简单来说就是在C盘属性中，利用磁盘清理系统文件，清理掉“旧的windows版本”。  
 再也回不去了！

#### 我的虚拟机没了

之前win10装VMware无果，发现了系统自带的虚拟机Hpyer-V，并且一直顺利使用~  
 升级win11后，不能用了！

 **如果你之前装了Hpyer，且还需要使用一段时间，不要升级win11，你会崩溃（电脑不会崩溃）**

#### 虚拟机监控程序无法运行

因为我之前写Android程序的时候要用AVD，与Hyper-V无法兼容，所以就使用命令关闭了Hyper-V。但是现在我又要用Hyper-V了，再用命令打开之后，却不能正常使用。经过我的寻找，发现**虚拟机监控程序无法勾选**。和网上的情况不一样，网上的问题大部分都是此处灰色无法选择，我的问题是：**选中虚拟机监控程序后，点击保存，再次打开仍是未选中的状态。**  
 ![在这里插入图片描述](https://i-blog.csdnimg.cn/blog_migrate/43c3b9746b932fa9a76f80ddc5c7276b.png)  
 **解决方案：** 重新加载Hyper-V，从新建文本文件开始，到重启计算机，然后按照配置控制面板，记事本中代码详见：[win10 家庭中文版没有Hyper-V，这样安装一步搞定](https://blog.csdn.net/weixin_37695006/article/details/91589895)  
 之前配置的虚拟机好像还在，不会被删掉。

#### win7

由于我需要使用Windows7操作系统的电脑，所以我又瞄准了我的Hyper-V。首先需要下载iso，因为微软官网现在不支持win7了，所以要自己找资源啦。（据我查阅资料，虚拟机用的iso和实体机直接装系统用的iso是同一种，可以共用的）我用的是这里博主在评论区分享的：[Cdboot：couldn‘t find bootmgr](https://blog.csdn.net/qq_44483628/article/details/124283004)

* 在创建虚拟机的时候，切记要把内存部分“动态分配内存”的选项取消，否则会卡在最后一步安装失败。另外启动内存要大于1024MB，建议是2048MB以上。
* 然后就可以启动虚拟机了，选择现在安装，注意安装的时候应该选择“自定义安装”而不是“升级”。
* 重点来了，在升级完之后，会有十几秒倒计时，这里要非常快地点击上方菜单栏“媒体”弹出你的iso，然后点右下角“立即重新启动”，如果不弹出，很有可能就会再次重新安装！重新启动之后，我的电脑又回到了那个安装界面，卡在了最后一步，但是不要着急，它过一会儿就会自动跳转！按照这个步骤绝对没有问题的！

此外，分享一下我遇到的问题，我在“展开Windows文件”这步卡住不动了，58%和86%都卡过，试过好几个办法都不行，就是任何操作都没问题（为什么没问题我就不说了，反正iso和操作步骤都没问题），最后我发现可能是因为我的内存爆了，我清理了内存之后就顺利了。

二、我的电脑使用手册
----------

这里总结在使用电脑或系统中遇到的问题

### 1. 显示器双屏/投屏/Win11投屏电视/笔记本投屏/小米

升级Win11之后投屏方式和之前不太一样了，然后把投屏放置总结了一下：  
 设备：小米笔记本+小米电视

**step1：连接电视**  
 （按原来的投屏键F6，只有投屏设置，没有连接设备了）  
 使用快捷键win+k，查找设备。

**step2：双屏设置**  
 快捷键win+shift+←/→，可以设置当前软件在哪个屏。

**记住这两个快捷键就够用了！**

### 2. 清理内存

有时候还没咋用，然后CPU就满了，明明不应该这样的！我以前的电脑真的非常干净。

1. 首先我自己独创的方法，就是把桌面清理干净，桌面上的东西太多不行！整理过后能感觉到内存条没有之前那么满了。怎么说呢，治标不治本吧。
2. 按Win + R打开运行窗口。在运行窗口中键入命令mdsched.exe。这个是一个内存修复，能解决大部分人的问题，我的情况也是这种方法解决的。
3. 我的电脑管家总是提示edge高内存。首先打开浏览器，进入设置→系统和性能，在“优化性能”部分设置如下：关闭启动增强、关闭在Microsoft Edge关闭后继续运行后台扩展和应用、关闭使用硬件加速、打开效率模式、打开使用标签页休眠功能节约资源、打开淡出睡眠标签页。然后重启浏览器。
4. 刚清理完，用了没多长时间又满了，于是我又搜索了一些方法。打开控制面板并点击“硬件和声音”，在新的窗口中可以看到“电源选项”，点击它，左侧有“选择电源按钮的功能”点击，然后点击“更改当前不可用的设置”，再取消勾选“启用快速启动”后保存。

参考：[解决win10一开机内存占用率70%多](https://blog.csdn.net/HL477/article/details/121903801)

### 4. iPhone和PC互传

我需要把iPhone上的媒体资料传到电脑里备份，发现有很多文件无法正常显示，比如`.MOV`格式、`.HEIC`格式、`.AEE`格式的文件。由于我需要保存live图，所以解决这些问题是非常必要的。

* `HEIF`文件：iPhone里有很多HEIF文件，它是一种可以把高清图片压缩的文件格式，比jpg更节省空间。`.HEIC`是HEIF文件的某一种后缀类型。
* `live`图片：手机里的live图在电脑里由两部分组成，一个是`.MOV`视频，另一个是`.HEIC`封面。用数据线将文件夹里的live图直接导出到电脑上，就分成了上述两个文件。
* `AEE`文件：作用是记录照片的修改。
* > “每当您使用“照片”应用编辑照片时，该应用都会创建一个带有 AAE 扩展名的特殊XML文件，其中包含有关对照片进行编辑的信息，以便可以保留原始照片而不进行任何更改，并且可以随时撤消编辑时间。”

参考：https://zhidao.baidu.com/question/1843357497609124020.html

#### LocalSend传输照片

在手机端和电脑端都下载LocalSend即可传输照片，不需要数据线（记得提前设置好接收地址），优点是照片几乎没有被压缩，缺点是无法保留live格式（手机传到电脑上就不是live图了，mov和heic传到手机里也不能自动合成live图）。

#### 爱思助手传输照片

在电脑上下载爱思助手，可以导入导出live图。如果爱思助手里不显示照片缩略图可以重启一下。
