✅ 集群
----

### 🔹🔹基础

| 命令 | 作用 |
| --- | --- |
| cat /etc/hosts | 查看集群中所有主机信息 |
| history | 查看历史命令 |
| qnodes -l all | 查看所有服务器状态 |

### 🔹🔹环境变量

| 命令 | 作用 |
| --- | --- |
| vim ~/.bashrc | 编辑环境变量的配置文件 |
| source ~/.bashrc | 刷新配置文件使其生效 |
| export http\_proxy=127.0.0.1:7890 | 联网 |
| export | 查看所有的环境变量 |
| alias <变量>=<替换为> | 设置别名 |

* 函数的使用：**export新建环境变量，unset撤销环境变量**。修改`~/.bashrc`文件后使用`source`刷新，在命令行通过函数名直接调用。如下图：

### 🔹🔹网络

| 命令 | 作用 |
| --- | --- |
| ip link show | 查看网络接口状态 |
| ifconfig | 查看所有接口 |

* 设置远程端口转发给集群联网：  
   本地终端：

  ```
  # ssh -R 10808:127.0.0.1:本地代理端口 用户名@远程IP
  ssh -R 10808:127.0.0.1:7897 dingjr@xxx.xxx.xxx.xx
  ```

  集群终端：

  ```
  vim ~/.bashrc
  # i进入编辑模式
  export http_proxy=socks5h://127.0.0.1:10808
  export https_proxy=socks5h://127.0.0.1:10808
  # ESC, “:wq”退出
  source ~/.bashrc
  # 跳转到计算节点
  ssh -R 10808:127.0.0.1:10808 gpu03
  ```

  ssh到github

  ```
  Host github.com
      HostName github.com
      User xxxx  # 用户名
      ProxyCommand ncat --proxy-type socks5 --proxy 127.0.0.1:10808 %h %p
      ServerAliveInterval 60
  ```

### 🔹🔹进程

| 命令 | 作用 |
| --- | --- |
| netstat -tunlp | grep <端口号> |
| kill -9 <进程号> | 杀死进程 |

将`Ctrl+c`误打成`Ctrl+z`后，进程会挂起，可使用`fg`将进程调回到前台。 `jobs`可以查看当前所有在后台被挂起或运行的任务列表及其编号。

### 🔹🔹会话

| 命令 | 作用 |
| --- | --- |
| tmux new -s {会话名} | 新建会话 |
| Ctrl+B -> D | 退出会话 |
| tmux attach -t {会话名字} | 查看会话 |
| exit | 结束会话 |

### 🔹🔹文件权限

| 命令 | 作用 |
| --- | --- |
| sudo chown {新所有者用户名} {文件夹路径} | 将文件夹的所有者更改为指定用户 |
| sudo chown {新所有者用户名}:{新组名} {文件夹路径} | 一次性同时修改文件夹的所有者和所属组 |
| sudo chown -R {新所有者用户名} {文件夹路径} | 递归更改文件夹内所有子文件夹和文件的所有权 |
| sudo chown :{新组名} {文件夹路径} | 仅更改所属组 |
| sudo chown --reference={参考文件} {目标文件} | 将目标文件夹的所有者和组设置为与参考文件相同 |

✅ 容器
----

| 命令 | 作用 | 参数 | 参数说明 |
| --- | --- | --- | --- |
| docker images | 查看本地所有镜像 |  |  |
| docker run <参数> <镜像名> | 新启容器 | –privileged | 赋予容器几乎所有的主机权限 |
|  |  | –network=host | 让容器共享主机的网络命名空间 |
|  |  | –gpus all | 分配所有可用的 GPU 给容器 |
|  |  | -m 150G | 指定容器最多可以使用150GB的内存 |
|  |  | –oom-kill-disable=true | 禁用OOM(Out of Memory)杀手 |
|  |  | –ulimit memlock=-1 | 不限制内存锁的大小 |
|  |  | –ulimit stack=67108864 | 将线程栈大小限制为67108864 字节(即 64MB) |
|  |  | –shm-size 32g | 设置容器中共享内存的大小为32GB |
|  |  | -it | 允许用户与容器进行交互，类似于进入一个 shell 环境 |
|  |  | –rm | 在容器退出时自动删除容器 |
|  |  | –name <容器名> |  |
|  |  | -v ~:/<`workspace`> | 将主机的目录挂载到容器中 |
| exit | 退出容器 |  |  |
| docker ps -a | 查看所有容器和ID |  |  |
| docker start <容器ID> | 启动容器（不进入） |  |  |
| docker exec -it <容器ID> /bin/bash | 进入容器（要先启动） |  |  |
| docker rm <容器ID> | 删除容器 |  |  |
