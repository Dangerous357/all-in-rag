# 2021数据库课程设计培训笔记：【navicat】部分

简单介绍一下navicat，一个方便控制数据库的软件。  
 **安装MySQL的时候，我们都以为它是可视化的，但其实不是，它没有工作台，只是在后台运行的，而且只能装在C盘。我们利用navicat，可以看到我们的数据库。**

### 一、连接本地数据库

输入连接名称、用户名和密码→点击测试连接按钮。  
 tips：若联网可之间连接，未联网的情况下接口要改为127.0.0.1（连接到本地）
