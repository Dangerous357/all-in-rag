# 微信客户端突然打不开网址和小程序，记得检查网络代理软件

![在这里插入图片描述](https://i-blog.csdnimg.cn/direct/d22a3ea89d944e09bf55bb8f843b6c0c.png)

最近微信电脑版突然打不开小程序了，今天发现网址链接也打不开，但是使用edge浏览器可以打开。提示“无法乱接到互联网”，“代理服务器”出现问题。最开始我以为是微信哪里的问题，删除微信缓存、删除applet文件夹，重启之后还是没办法解决。

我把关注点放在代理服务器上，我好像没有开过代理。再次检查了系统设置中关于代理的设置，全部关闭后重启微信也没解决。  
 ![在这里插入图片描述](https://i-blog.csdnimg.cn/direct/6c161faf4b7c4d0194f75b37e762e70c.png)

我想起前几天edge也连不上网，我把插件从系统代理改成直接连接后才连上。于是我换了chrome浏览器，chrome浏览器也无法访问互联网。（看来是我冤枉微信了）我打开网络诊断工具，“远程计算机或设备将不接受连接”。  
 ![在这里插入图片描述](https://i-blog.csdnimg.cn/direct/437220ce61ef477d914dc7fab4453867.png)

我查到几个原因，对我来说最有可能的是“网络代理软件在关闭之前没有关闭代理”，于是我打开软件发现果然系统代理是开着的，此时问题解决。  
 ![在这里插入图片描述](https://i-blog.csdnimg.cn/direct/5b85dd0d63264a93bf31f56faeded340.png)

都怪那天晚上电脑趁我不在的时候自动更新！所以我的网络代理软件被强制关闭了，才导致突然出了各种各样的网络问题。自动更新对不喜欢关机的人来说真的很不友好，经常第二天一大早发现电脑自己变样了以后下班一定要注意⚠️①保存文件②关掉代理
