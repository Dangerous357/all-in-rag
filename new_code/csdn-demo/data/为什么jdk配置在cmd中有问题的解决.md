# 为什么jdk配置在cmd中有问题的解决

**问题背景：**  
很早之前下载的eclipse和jdk，环境变量也是很早之前就配置的。写程序的时候一直用eclipse，老师让用cmd弄一次，发现有错误。

**你可能和我存在的共性问题：**  
刚开始以为是环境变量配置有问题，于是又照着网上改了很多遍，但是还是没有办法解决。甚至原来java正常，javac不正常，现在java和javac都不能用了。

**最后的解决方案：**  
我发现我的jdk文件夹里面，有一个javatwo文件夹（至于为什么是这个名字，可能是我当时下载东西的时候自己起的，因为我没有百度到这个文件夹，毕竟当时啥也不知道，乱下载），我还发现了javatwo中也有java.exe。于是我尝试把javatwo中的文件复制到jdk子文件夹对应的地方，同名文件直接替换掉。  
那么所有cmd可能会用到的文件，都被我放在一起了。  
然后，cmd的java和javac命令都可以正常使用了。
