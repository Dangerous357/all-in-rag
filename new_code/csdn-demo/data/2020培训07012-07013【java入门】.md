### 数据类型

##### 一、整数类型

byte：字节 存储范围 -128~127 占内存1字节（8位）  
short：短整型 -32768~32767 占内存2字节（16位）  
int：整型 -2147483647~2147483647 占内存4字节（32位）  
long：长整型 -9223372036854775808~9223372036854775807  
占内存8字节（64位）  
**java中默认将所有的整数都当成int类型处理**

##### 二、浮点类型

double：双精度浮点 占内存8字节（64位）  
float：单精度浮点 占内存4字节（32位）  
**java中默认将所有的小数都当成double类型处理，例：强制类型转换float a=3.0f; 等价接收 double a=3.0;**

##### 三、布尔类型

boolean：值为true或false 不占内存空间

##### 四、字符类型

char：字符 占内存2字节（16位）（2字节可存储汉字）

### 变量

##### 一、常量

**初始值为一个值，未来永远不会改变的值**  
例：" "中的值，如何书写就如何打印，原样输出`System.out.println("1+2");`

##### 二、变量

**初始值为一个值，未来可能会发生变化的值**

* 语法：数据类型 变量名=对应类型的数据
* 变量名：不能以数字开头、首字母小写、不能有特殊符号、不能用java关键字、变量名驼峰式
* 变量的作用域（有效范围）：  
  如何查看变量的有效范围？离他上下最近的成对大括号之间  
  1.局部变量：在方法体内出生的变量被称之为局部变量  
  2.全局变量：在类体之间，类名下方出生的变量被称之为全局变量
